WordPress requires the theme screenshot at /screenshot.png (1200x900).

screenshot.svg has been generated as a high-quality preview. To produce
the PNG WP-Admin uses, run ONE of the following from this directory:

  # ImageMagick / Inkscape
  magick screenshot.svg -resize 1200x900 screenshot.png
  inkscape screenshot.svg --export-type=png --export-width=1200 --export-filename=screenshot.png

  # rsvg-convert
  rsvg-convert -w 1200 -h 900 screenshot.svg > screenshot.png

  # Online converter (no installs):
  Upload screenshot.svg to https://cloudconvert.com/svg-to-png
  Set output to 1200x900, download as screenshot.png
  Drop into the theme root next to screenshot.svg.

Once screenshot.png exists, Appearance → Themes will show the preview.
