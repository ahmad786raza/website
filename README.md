# Theme upgrades workspace

Two WordPress sites share this repository. Each theme folder starts from the zip the owner supplied (first commit for that theme), so `git log -- <folder>` shows every change.

## hoverboardsguide.com — Hoverboards Guide theme (October 2026)

| Path | What it is |
|---|---|
| `hoverboards-guide/` | Theme source, **v3.0.0 "Magazine"** (upgraded from the supplied v2.1.0). |
| `dist/hoverboards-guide-3.0.0.zip` | Upload-ready zip (Appearance → Themes → Add New → Upload → *Replace current with uploaded*). |
| `docs/HOVERBOARDS-REPORT.md` | Delivery report: audit, what changed, tests, install steps, rollback, outstanding items, next steps. |
| `docs/HOVERBOARDS-CONTENT-REVIEW.md` | Published passages (ratings, testing claims, conflicting specs) that need the owner's edits. |
| `docs/research/hoverboards-competitors.md` | Competitor/reference research and sources. |
| `docs/screenshots/hbg-*` | Before (v2.1 live) and after (v3 local) screenshots. |

Read `docs/HOVERBOARDS-REPORT.md` before installing.

## bendershub.com — Benders Hub Pro theme

| Path | What it is |
|---|---|
| `benders-hub-pro/` | WordPress theme source, **v2.0.5** (magazine redesign). |
| `dist/benders-hub-pro-2.0.5.zip` | Upload-ready theme zip. |
| `docs/REPORT.md` | Upgrade report: problems found, changes, tests, performance, install, rollback and next steps. |
| `docs/CONTENT-REVIEW.md` | Passages in already-published posts and pages that need correcting. |
| `docs/research/` | Competitor matrix, keyword/content-gap plan, technical fact-check, and image candidates with licence notes. |
| `content/` | Article kit for bendershub.com. |
