# bendershub.com — Benders Hub Pro theme

| Path | What it is |
|---|---|
| `benders-hub-pro/` | WordPress theme source, **v2.0.0** (magazine redesign). The first commit is the v1.0.0 theme exactly as supplied, so `git diff` shows every change. |
| `dist/benders-hub-pro-2.0.0.zip` | Upload-ready theme zip (Appearance → Themes → Add New → Upload). |
| `docs/REPORT.md` | Upgrade report: problems found, changes, tests, performance, install, rollback and next steps. |
| `docs/CONTENT-REVIEW.md` | Passages in already-published posts and pages that need correcting. |
| `docs/research/` | Competitor matrix, keyword/content-gap plan, technical fact-check, and image candidates with licence notes. |
| `docs/screenshots/` | Before/after screenshots from local testing. |

Read `docs/REPORT.md` §11 before installing.
