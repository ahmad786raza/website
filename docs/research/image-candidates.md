# Image candidates and licence records

Status on delivery: **no images have been imported yet.** This environment could not reach Wikimedia Commons, Pexels or your site, so the photos below are *candidates*. Run **Benders Hub → Image Library** on your site:

1. **Check all Commons licences.** Your server asks the live Commons API for each file's current licence, author and download URL. Only CC0, public domain, CC BY and CC BY-SA are accepted. NC and ND licences, missing files and non-image files are refused automatically. The "research licence" column below is what the research found; the importer does not rely on it.
2. **Look at every preview** and approve only photos that clearly show the subject. Check the notes for trademarks and identifiable people. Edit the alt text so it describes what is visible.
3. **Pexels photos.** Open the Pexels page and tick the confirmation box before importing.

For each imported photo, the Media Library records the source URL, creator, licence, licence URL and import date. The caption is set to `Photo: {creator} / {licence}` and appears under featured images. The `[bdh_image_credits]` shortcode (or the "Create an Image credits page" button) lists every imported photo with its attribution. CC BY and CC BY-SA require attribution.
